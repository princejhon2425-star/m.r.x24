M.R.X COMPUTER SOLUTIONS
PRIVATE EDITING SETUP

WHAT THIS SETUP DOES

The admin page lets you edit product listings, personalize supported page text,
and view/update requests saved by this browser. The current website is static:
the dashboard does not edit the HTML files and does not send data to a server.
Its saved data stays in this browser profile on this computer.

FIRST-TIME SETUP ON WINDOWS

1. Keep the whole project together in one folder, for example:
   C:\Users\M.R.X\Documents\m.r.x web

2. Confirm that these files are together in that folder:
   admin.html
   admin.js
   mrx-site.js
   acrylic-buttons.css
   index.html
   home.html
   computer-repair.html
   computer-sales.html
   submitted.html
   Any images used by the pages

3. Install Python from https://www.python.org/downloads/ if the "py" command
   is not available on your computer.

4. Open Windows PowerShell.

5. Start a local-only web server by running these commands:
   cd "C:\Users\M.R.X\Documents\m.r.x web"
   py -m http.server 8000 --bind 127.0.0.1

   If your computer uses "python" instead of "py", run:
   python -m http.server 8000 --bind 127.0.0.1

   Keep this PowerShell window open while you use the site. The 127.0.0.1
   binding makes this server accessible only from this computer.

6. In the same browser profile where you want to keep your edits, open:
   http://127.0.0.1:8000/admin.html

7. Open the public-facing pages on this same local server when you want to
   preview your edits:
   http://127.0.0.1:8000/index.html
   http://127.0.0.1:8000/computer-sales.html
   http://127.0.0.1:8000/submitted.html

USING THE DASHBOARD

- Products: add, edit, or delete products. Product details appear on the
  computer-sales page in this same browser. Drag one JPG, PNG, or WebP image
  into the product image area, or choose an image from your device. Images are
  resized and saved with the product in this browser.
- Page personalization: edit the supported text fields, save, then reload the
  affected page to see the change.
- Requests: requests submitted through this same local site appear here.
  Update a request's status, then reload its confirmation page to see the
  current ticket's saved status.

IMPORTANT LIMITATIONS

- Use the same computer, browser profile, and exact address
  (http://127.0.0.1:8000) each time. Browser storage is separate for different
  browsers, browser profiles, computers, and website addresses.
- Do not use a private/incognito window for changes you want to keep.
- Clearing this site's browser data can erase products, page copy, and requests.
  Back up browser data before clearing it; this dashboard does not yet include
  a backup/export feature.
- This is not a secure login. Anyone who can access the local dashboard in
  your browser can change its data. Do not expose it on a public server or
  store sensitive customer information in it.
- The dashboard saves browser data, not changes to the HTML source files.
  Browser-local edits do not automatically publish to your public website.

TO STOP THE SERVER

Return to the PowerShell window running the server and press Ctrl+C.
